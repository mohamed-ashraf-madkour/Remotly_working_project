# 📊 Remote Working Analysis Dashboard

An interactive Power BI dashboard project analyzing remote work trends, employee preferences, productivity, benefits, and challenges.

---

# 📌 Project Overview
This project explores how employees experienced remote work and how their preferences, productivity, and challenges changed in remote working environments.

The dashboard provides business insights that help organizations better understand:
- Employee remote work preferences
- Productivity perception
- Work-life balance impact
- Main remote work barriers
- Differences across industries and occupations

---

# 🛠️ Tools Used

- Power BI
- Excel
- Data Cleaning
- Data Visualization
- DAX

---

# 📂 Dashboard Structure

## 🟦 1. Overview Dashboard
Provides a high-level summary of remote work trends.

### Includes:
- Remote work adoption
- total perfered employees to remote work
- Managers vs non-managers comparison

### Key Insight:
- total employees
- total industeries
- total jobs
- total managers

---

## 🟩 2. Benefits Dashboard
Explores the major advantages of remote work.

### Includes:
- Best aspects of remote work
- Work-life balance impact
- Commuting time reduction
- Productivity perception

### Key Insight:
- total employees
- total industeries
- total jobs
- total managers

---

## 🟥 3. Barriers Dashboard
Analyzes the biggest challenges employees face while working remotely.

### Includes:
- Most significant barriers

- total managers

## 🟨 4. Segmentation Dashboard
Compares remote work experiences across different employee groups.

### Includes:

### Key Insight:
- total employees
- total industeries
- total jobs
- total managers
